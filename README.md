# Rocket Launcher Marketplace

เว็บกลางสำหรับ Script, Color และ Graphic Style ของพาเนล Rocket Launcher ใช้บน Hostinger shared hosting ได้

เว็บนี้แสดงรายการ สมาชิกเข้าสู่ระบบด้วย Google แล้วกด Star เพื่อเก็บรายการเข้า Library ของตัวเอง และลบรายการของตัวเองได้ แต่ละรายการอยู่ได้ 10 วัน มีคนดาวน์โหลดไปใช้แล้วจะต่อเวลาอีก 10 วัน รายการที่หมดอายุจะถูกลบ การเพิ่มทำจากพาเนล หลังผู้ใช้กดเชื่อมต่อด้วย Google หนึ่งครั้ง โทเคนจากหน้า setup เป็นของคนดูแลระบบ ใช้ลบรายการใดก็ได้ ไม่ต้องให้ผู้ใช้ใส่

## ชนิดรายการ

| ชนิด | สิ่งที่เก็บ |
|---|---|
| Script | ไฟล์ `.jsx` ไม่เกิน 2 MB |
| Color | รหัสสี 1–8 สี ไม่มีไฟล์ |
| Graphic Style | ไฟล์ `.ai` ไม่เกิน 40 MB และรูปตัวอย่างคำว่า TEXT เป็น PNG หรือ JPEG ไม่เกิน 2 MB |

## ขีดจำกัด

- สมาชิกหนึ่งคนอัปโหลดได้ 20 รายการต่อ 24 ชั่วโมง (เกินแล้วได้ 429)
- พื้นที่รวมของทุกรายการไม่เกิน 2048 MB (เต็มแล้วได้ 507)
- Graphic Style ต้องเป็นไฟล์ Illustrator จริง (ขึ้นต้นด้วย `%PDF` หรือ `%!PS-Adobe`) Script ต้องเป็นไฟล์ข้อความ
- เริ่มเชื่อมพาเนลได้ 20 ครั้งต่อ 10 นาทีต่อที่อยู่ IP (เกินแล้วได้ 429)
- การดาวน์โหลดนับหนึ่งครั้งต่อผู้ใช้ต่อวัน กดซ้ำไม่เพิ่มยอด

สองค่าแรกเปลี่ยนได้ใน `config.json` ด้วย `max_uploads_per_day` และ `max_storage_mb`

## ความปลอดภัยและความทนทาน

- หน้าเว็บถูกฝังใน iframe ของเว็บอื่นไม่ได้ และไม่รันสคริปต์ใดเลย (`Content-Security-Policy`, `X-Frame-Options`)
- หน้าอนุญาตพาเนลแสดงรหัสเชื่อมต่อ พาเนลก็แสดงรหัสเดียวกัน ให้กดอนุญาตเมื่อรหัสตรงกันเท่านั้น
- โทเคนของพาเนลส่งให้พาเนลครั้งเดียว เซิร์ฟเวอร์เก็บแค่ค่า hash ออกจากบัญชีในพาเนลแล้วโทเคนใช้ไม่ได้ทันที สมาชิกกด "ตัดการเชื่อมต่อทั้งหมด" บนเว็บได้
- ออกจากระบบต้องกดปุ่มบนเว็บ (POST พร้อม CSRF)
- `setup.php` ปิดตัวเองเมื่อใส่ Google ครบ และไม่สร้าง `config.json` ทับไฟล์ที่เสีย
- ไฟล์ข้อมูลเขียนแบบไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ และเก็บรุ่นก่อนหน้าเป็น `.bak` ถ้าไฟล์อ่านไม่ได้ ระบบใช้ `.bak` แทน ถ้าอ่านไม่ได้ทั้งคู่ระบบจะหยุดรับคำขอ (503) แทนที่จะถือว่ารายการว่างแล้วเขียนทับ
- ทุกชั่วโมงระบบลบรายการหมดอายุ ไฟล์ที่ไม่มีรายการอ้างถึง (ที่เก่ากว่าหนึ่งชั่วโมง) และคำขอเชื่อมต่อที่หมดเวลา
- `config.json`, `storage/*.json`, ไฟล์ `.bak` `.tmp`, โฟลเดอร์ที่ขึ้นต้นด้วยจุดและ `tests/` ไม่เปิดให้อ่านจากเว็บ

## ความเร็ว

- คนที่ยังไม่ได้ล็อกอินและพาเนลไม่ได้ session ใหม่ การอ่านรายการไม่ล็อกไฟล์
- `list.php` ส่ง `ETag` รายการเดิมตอบ 304 แบบไม่มีเนื้อหา รูปตัวอย่างแคชในเบราว์เซอร์และพาเนล 30 วัน (บน CDN 1 วัน เพื่อไม่ให้รูปของรายการที่ลบค้างอยู่) เพราะรูปของแต่ละรายการไม่เปลี่ยน
- รูปบนหน้าเว็บโหลดเมื่อเลื่อนถึง

## API

| ทาง | งาน |
|---|---|
| `GET /api/list.php` | รายการทั้งหมด เป็น JSON ใส่ `?type=script` `color` หรือ `style` ได้ |
| `GET /api/library.php` | รายการที่ผู้ใช้ Star ไว้ ต้องมีเซสชันที่ล็อกอินแล้ว |
| `GET /api/download.php?id=` | ดาวน์โหลด Script หรือ Graphic Style Color ส่ง JSON ของชุดสี การดาวน์โหลดต่ออายุรายการเป็น 10 วันและเพิ่มจำนวนโหลด |
| `GET /api/preview.php?id=` | รูปตัวอย่างของ Graphic Style |
| `POST /api/panel.php` `action=start` | เริ่มเชื่อมพาเนลกับบัญชี Google ได้ `device_code`, `user_code` และ `verify_url` |
| `GET /api/panel.php?device=` | ตรวจว่าผู้ใช้กดอนุญาตบนเว็บแล้วหรือยัง ได้ `pending`, `approved` (พร้อมโทเคน ครั้งเดียว) หรือ `expired` |
| `POST /api/panel.php` `action=profile` | ชื่อและรูปของบัญชี ส่ง `panel_token` |
| `POST /api/panel.php` `action=logout` | ยกเลิกโทเคนของพาเนลนี้ ส่ง `panel_token` |
| `POST /api/upload.php` | เพิ่มรายการจากพาเนลที่เชื่อมต่อแล้ว ส่ง `panel_token` คนดูแลส่งโทเคนอัปโหลดแทนได้ |
| `POST /api/star.php` | สลับ Star ต้องล็อกอินและส่ง `csrf` |
| `POST /api/delete.php` | ลบรายการ เจ้าของส่ง `panel_token` คนดูแลส่งโทเคนอัปโหลด (ลบได้ทุกรายการ) |

อัปโหลดส่งแบบ `multipart/form-data` ด้วยฟิลด์ `type` (`script`, `color`, `style`), `name`, `description` Color ใช้ฟิลด์ `colors` Graphic Style ใช้ `file` และ `preview` Script ใช้ `file` พาเนลส่ง `panel_token` ที่ได้หลังกดอนุญาต โทเคนของคนดูแลส่งเป็นฟิลด์ `token` หรือหัว `X-Upload-Token`

## ขึ้น Hostinger ผ่าน GitHub

1. ใน hPanel เปิด Git แล้วเชื่อม repo นี้ ชี้โดเมนมาที่รากของ repo
2. เปิด `https://โดเมน/setup.php` หนึ่งครั้ง แล้วเก็บโทเคนที่แสดง
3. ใน Google Cloud สร้าง OAuth client ชนิด Web แล้วใส่ Redirect URI ที่หน้า setup แสดง
4. กลับมาที่ `setup.php` ใส่โทเคนเดิม, ที่อยู่เว็บ, client id และ client secret
5. ลบ `setup.php` บนเซิร์ฟเวอร์หลังเก็บค่าแล้ว (ถ้ายังไม่ลบ หน้านี้จะปิดตัวเองเมื่อใส่ Google ครบ หลังจากนั้นเปลี่ยนค่าได้ทาง `config.json` ใน File Manager)

การดึง Git จะไม่ทับ `config.json` กับไฟล์ใน `storage/` เพราะไฟล์พวกนั้นไม่อยู่ใน repo อย่าลบโฟลเดอร์ `storage` ตอน deploy

สำรองข้อมูลด้วยการดาวน์โหลด `config.json` และโฟลเดอร์ `storage/` จาก File Manager เป็นระยะ

## ทดสอบ

```bash
php tests/run.php
```

เทสต์คัดลอกเว็บไปไว้ในโฟลเดอร์ชั่วคราว เปิดเซิร์ฟเวอร์ในตัวของ PHP แล้วเรียกทุก API และหน้าเว็บแบบเดียวกับพาเนลและเบราว์เซอร์ ไม่แตะข้อมูลจริง ต้องมี PHP 8 พร้อม curl GitHub Actions รันเทสต์นี้และ `php -l` ทุกครั้งที่ push และเปิด PR (`.github/workflows/ci.yml`)
