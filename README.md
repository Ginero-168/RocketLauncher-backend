# Rocket Launcher

เว็บของพาเนล Rocket Launcher (https://rl.kirita.me) ใช้บน Hostinger shared hosting ได้ มีสามหน้า

- **หน้าแรก** (`index.php`) ปุ่มดาวน์โหลดไฟล์ติดตั้ง `.zxp` วิดีโอแนะนำพาเนล ฟีเจอร์ และขั้นตอนติดตั้ง
- **Marketplace** (`market.php`) Script, Color และ Graphic Style จากผู้ใช้ สมาชิกเข้าสู่ระบบด้วย Google แล้วกด Star เก็บเข้า Library และลบรายการของตัวเองได้ การเพิ่มทำจากพาเนลหลังกดเชื่อมต่อด้วย Google หนึ่งครั้ง
- **Admin** (`admin.php`) ตั้งค่าเว็บ AI กลาง ไฟล์ติดตั้ง และดูแลรายการ สมาชิก ผู้ดูแล

แต่ละรายการใน Marketplace อยู่ได้ตามจำนวนวันที่ตั้งใน Admin (เริ่มต้น 10 วัน) มีคนดาวน์โหลดไปใช้แล้วต่อเวลาใหม่ รายการที่หมดอายุจะถูกลบ

## Admin

1. เข้าสู่ระบบด้วย Google แล้วเปิด `admin.php`
2. ใส่โทเคนจากหน้า setup (ค่า `upload_token` ใน `config.json`) หนึ่งครั้ง บัญชีนั้นจะเป็นผู้ดูแล (ลองผิดได้ 5 ครั้งต่อ 10 นาที) ผู้ดูแลเพิ่มคนอื่นได้ด้วยวิธีเดียวกัน และเอาผู้ดูแลออกได้ ยกเว้นคนสุดท้าย

| ส่วน | ตั้งอะไรได้ |
|---|---|
| ตั้งค่า Marketplace | วันหมดอายุ (1–365), ขนาด Script / Graphic Style / รูปตัวอย่างสูงสุด, จำนวนอัปโหลดต่อคนต่อวัน, พื้นที่รวม, จำนวนครั้งที่เริ่มเชื่อมพาเนลได้ต่อ 10 นาที, เปิดปิดการรับแต่ละชนิด, โหมดปิดปรับปรุง (ดาวน์โหลดได้ แต่อัปโหลด Star ลบไม่ได้), เชื่อ `X-Forwarded-For` (เปิดเมื่อ "ข้อมูลเซิร์ฟเวอร์" ในส่วนภาพรวมแสดงว่า IP ที่ระบบใช้ไม่ใช่ IP จริงของคุณ เพราะเว็บอยู่หลัง CDN), ขนาดไฟล์ติดตั้งสูงสุด |
| AI กลาง | เปิดปิด AI, Replicate API key (เก็บใน `config.json` ไม่แสดงกลับ), โมเดล, โควตาต่อสมาชิกต่อวัน, โควตารวมทั้งเว็บต่อวัน, ความยาวข้อความสูงสุด, ปุ่มทดสอบ key |
| ไฟล์ติดตั้งพาเนล | อัปโหลด `.zxp` ที่เซ็นแล้ว (ตรวจว่าเป็น `com.tata.pro` มีลายเซ็น และอ่านเวอร์ชันจาก manifest) พร้อมบันทึกว่ามีอะไรใหม่ ไฟล์ใหม่แทนไฟล์เดิม ปุ่มดาวน์โหลดหน้าแรกและปุ่ม Check for updates ในพาเนลใช้ไฟล์นี้ |
| รายการ / สมาชิก / ผู้ดูแล | ลบรายการใดก็ได้ ตัดการเชื่อมต่อพาเนลของสมาชิก จัดการผู้ดูแล |
| บันทึกการเปลี่ยนแปลง | ใครเปลี่ยนอะไรเมื่อไร (300 รายการล่าสุด) |

ค่าที่ตั้งเก็บใน `storage/settings.json` ค่าที่อยู่นอกช่วงจะถูกปรับเข้าช่วงก่อนบันทึก

## AI กลาง

พาเนล 3.3.0 ขึ้นไปไม่มีช่องใส่ API key สมาชิกกดเชื่อมต่อด้วย Google ในพาเนล (บัญชีเดียวกับ Marketplace) แล้วใช้ AI ได้ทันที เว็บเรียก Replicate ด้วย key ของเว็บ ใส่ system prompt และเลือกโมเดลเอง พาเนลส่งแค่ข้อความของผู้ใช้

- นับโควตาต่อสมาชิกต่อวันและรวมทั้งเว็บต่อวัน (เวลาไทย) คำขอที่ Replicate ปฏิเสธหรือเรียกไม่ได้ไม่นับ
- คำตอบที่ยังไม่เสร็จใน 25 วินาที เว็บตอบ `processing` พร้อม id พาเนลถามซ้ำได้เฉพาะ id ของตัวเอง
- ข้อความผิดพลาดจาก Replicate ไม่ถูกส่งต่อ (ไม่มี key หลุดไปที่พาเนล)

## วิดีโอแนะนำ

## ชนิดรายการ

| ชนิด | สิ่งที่เก็บ |
|---|---|
| Script | ไฟล์ `.jsx` (เริ่มต้นไม่เกิน 2 MB) |
| Color | รหัสสี 1–8 สี ไม่มีไฟล์ |
| Graphic Style | ไฟล์ `.ai` (เริ่มต้นไม่เกิน 40 MB) และรูปตัวอย่างคำว่า TEXT เป็น PNG หรือ JPEG (เริ่มต้นไม่เกิน 2 MB) |

## ขีดจำกัด

ค่าเริ่มต้นด้านล่างเปลี่ยนได้ในหน้า Admin

- สมาชิกหนึ่งคนอัปโหลดได้ 20 รายการต่อ 24 ชั่วโมง (เกินแล้วได้ 429)
- พื้นที่รวมของทุกรายการไม่เกิน 2048 MB (เต็มแล้วได้ 507)
- Graphic Style ต้องเป็นไฟล์ Illustrator จริง (ขึ้นต้นด้วย `%PDF` หรือ `%!PS-Adobe`) Script ต้องเป็นไฟล์ข้อความ
- เริ่มเชื่อมพาเนลได้ 20 ครั้งต่อ 10 นาทีต่อที่อยู่ IP (เกินแล้วได้ 429)
- AI ใช้ได้ 30 ครั้งต่อสมาชิกต่อวัน และ 500 ครั้งต่อวันทั้งเว็บ
- การดาวน์โหลดนับหนึ่งครั้งต่อผู้ใช้ต่อวัน กดซ้ำไม่เพิ่มยอด

ค่า `max_uploads_per_day` และ `max_storage_mb` ใน `config.json` ของเว็บรุ่นก่อนยังใช้เป็นค่าเริ่มต้น จนกว่าจะบันทึกในหน้า Admin

## ความปลอดภัยและความทนทาน

- หน้าเว็บถูกฝังใน iframe ของเว็บอื่นไม่ได้ และไม่รันสคริปต์ใดเลย (`Content-Security-Policy`, `X-Frame-Options`)
- หน้าอนุญาตพาเนลแสดงรหัสเชื่อมต่อ พาเนลก็แสดงรหัสเดียวกัน ให้กดอนุญาตเมื่อรหัสตรงกันเท่านั้น
- โทเคนของพาเนลส่งให้พาเนลครั้งเดียว เซิร์ฟเวอร์เก็บแค่ค่า hash ออกจากบัญชีในพาเนลแล้วโทเคนใช้ไม่ได้ทันที สมาชิกกด "ตัดการเชื่อมต่อทั้งหมด" บนเว็บได้
- ออกจากระบบต้องกดปุ่มบนเว็บ (POST พร้อม CSRF)
- `setup.php` ปิดตัวเองเมื่อใส่ Google ครบ และไม่สร้าง `config.json` ทับไฟล์ที่เสีย
- ไฟล์ข้อมูลเขียนแบบไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ และเก็บรุ่นก่อนหน้าเป็น `.bak` ถ้าไฟล์อ่านไม่ได้ ระบบใช้ `.bak` แทน ถ้าอ่านไม่ได้ทั้งคู่ระบบจะหยุดรับคำขอ (503) แทนที่จะถือว่ารายการว่างแล้วเขียนทับ
- ทุกชั่วโมงระบบลบรายการหมดอายุ ไฟล์ที่ไม่มีรายการอ้างถึง (ที่เก่ากว่าหนึ่งชั่วโมง) และคำขอเชื่อมต่อที่หมดเวลา
- `config.json`, `storage/*.json`, ไฟล์ `.bak` `.tmp`, โฟลเดอร์ที่ขึ้นต้นด้วยจุดและ `tests/` ไม่เปิดให้อ่านจากเว็บ

## ความเร็ว

- คนที่ยังไม่ได้ล็อกอินและพาเนลไม่ได้ session ใหม่ การอ่านรายการไม่ล็อกไฟล์
- `list.php` ส่ง `ETag` รายการเดิมตอบ 304 แบบไม่มีเนื้อหา รูปตัวอย่างแคชในเบราว์เซอร์และพาเนล 30 วัน (บน CDN 1 วัน เพื่อไม่ให้รูปของรายการที่ลบค้างอยู่) เพราะรูปของแต่ละรายการไม่เปลี่ยน
- รูปบนหน้าเว็บโหลดเมื่อเลื่อนถึง

## API

| ทาง | งาน |
|---|---|
| `GET /api/list.php` | รายการทั้งหมด เป็น JSON ใส่ `?type=script` `color` หรือ `style` ได้ |
| `GET /api/library.php` | รายการที่ผู้ใช้ Star ไว้ ต้องมีเซสชันที่ล็อกอินแล้ว |
| `GET /api/download.php?id=` | ดาวน์โหลด Script หรือ Graphic Style Color ส่ง JSON ของชุดสี การดาวน์โหลดต่ออายุรายการเป็น 10 วันและเพิ่มจำนวนโหลด |
| `GET /api/preview.php?id=` | รูปตัวอย่างของ Graphic Style |
| `POST /api/panel.php` `action=start` | เริ่มเชื่อมพาเนลกับบัญชี Google ได้ `device_code`, `user_code` และ `verify_url` |
| `GET /api/panel.php?device=` | ตรวจว่าผู้ใช้กดอนุญาตบนเว็บแล้วหรือยัง ได้ `pending`, `approved` (พร้อมโทเคน ครั้งเดียว) หรือ `expired` |
| `POST /api/panel.php` `action=profile` | ชื่อและรูปของบัญชี ส่ง `panel_token` |
| `POST /api/panel.php` `action=logout` | ยกเลิกโทเคนของพาเนลนี้ ส่ง `panel_token` |
| `POST /api/upload.php` | เพิ่มรายการจากพาเนลที่เชื่อมต่อแล้ว ส่ง `panel_token` คนดูแลส่งโทเคนอัปโหลดแทนได้ |
| `POST /api/star.php` | สลับ Star ต้องล็อกอินและส่ง `csrf` |
| `POST /api/delete.php` | ลบรายการ เจ้าของส่ง `panel_token` คนดูแลส่งโทเคนอัปโหลด (ลบได้ทุกรายการ) |
| `GET /api/info.php` | ค่าที่พาเนลและหน้าแรกใช้: วันหมดอายุ ขนาดไฟล์สูงสุด ชนิดที่เปิดรับ สถานะ AI และไฟล์ติดตั้งปัจจุบัน (เวอร์ชัน ขนาด SHA-256 บันทึก) |
| `POST /api/ai.php` `action=start` | AI กลาง ส่ง `panel_token` และ `prompt` ได้ `succeeded` พร้อม `output` หรือ `processing` พร้อม `id` และ `remaining` (โควตาที่เหลือวันนี้) |
| `POST /api/ai.php` `action=poll` | ถามผลของคำขอที่ยัง `processing` ส่ง `panel_token` และ `id` |
| `GET /download.php` | ดาวน์โหลดไฟล์ติดตั้ง `.zxp` ล่าสุด |

อัปโหลดส่งแบบ `multipart/form-data` ด้วยฟิลด์ `type` (`script`, `color`, `style`), `name`, `description` Color ใช้ฟิลด์ `colors` Graphic Style ใช้ `file` และ `preview` Script ใช้ `file` พาเนลส่ง `panel_token` ที่ได้หลังกดอนุญาต โทเคนของคนดูแลส่งเป็นฟิลด์ `token` หรือหัว `X-Upload-Token`

## ขึ้น Hostinger ผ่าน GitHub

1. ใน hPanel เปิด Git แล้วเชื่อม repo นี้ ชี้โดเมนมาที่รากของ repo
2. เปิด `https://โดเมน/setup.php` หนึ่งครั้ง แล้วเก็บโทเคนที่แสดง
3. ใน Google Cloud สร้าง OAuth client ชนิด Web แล้วใส่ Redirect URI ที่หน้า setup แสดง
4. กลับมาที่ `setup.php` ใส่โทเคนเดิม, ที่อยู่เว็บ, client id และ client secret
5. ลบ `setup.php` บนเซิร์ฟเวอร์หลังเก็บค่าแล้ว (ถ้ายังไม่ลบ หน้านี้จะปิดตัวเองเมื่อใส่ Google ครบ หลังจากนั้นเปลี่ยนค่าได้ทาง `config.json` ใน File Manager)

6. เปิด `admin.php` ใส่โทเคนเดิมเพื่อเป็นผู้ดูแล แล้วใส่ Replicate API key ในส่วน AI กลาง และอัปโหลดไฟล์ `.zxp`

การดึง Git จะไม่ทับ `config.json` กับไฟล์ใน `storage/` (รวม `settings.json`, `ai.json`, `release.json` และ `releases/`) เพราะไฟล์พวกนั้นไม่อยู่ใน repo อย่าลบโฟลเดอร์ `storage` ตอน deploy

สำรองข้อมูลด้วยการดาวน์โหลด `config.json` และโฟลเดอร์ `storage/` จาก File Manager เป็นระยะ

## ทดสอบ

```bash
php tests/run.php
```
